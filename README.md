# TanatousStudio – Creative Landing Page

**Live Demo**: [ramitaleb27.github.io/TanatousStudio-LandingPage](https://ramitaleb27.github.io/TanatousStudio-LandingPage/)

TanatousStudio is a visually appealing and fully responsive landing page designed for a creative or design studio. Built with clean code and elegant visuals, this project demonstrates front-end development skills and UI/UX design sensibility.

## 🚀 Features

- 🎨 Modern and minimalistic design
- 📱 Fully responsive across all devices
- 🖼️ Hero section with impactful message
- 🧩 Modular layout using HTML/CSS/JS
- ⚡ Smooth transitions and hover effects
- 🌐 Deployed with GitHub Pages

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
- -** Bootstraps
- **Font Awesome** (for icons)
- **Google Fonts**
- **GitHub Pages** for deployment

```bash
git clone https://github.com/ramitaleb27/TanatousStudio-LandingPage.git

2. Navigate to the project folder:



cd TanatousStudio-LandingPage

3. Open index.html in your browser.



No build process needed – it's a pure static site.

📦 Deployment

This project is live via GitHub Pages. To deploy your own version:

1. Push your project to a GitHub repository


2. Go to Settings > Pages


3. Choose main branch and /root folder


4. Save and your site will be published shortly
